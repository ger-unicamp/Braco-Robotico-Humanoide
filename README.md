# Braco-Robotico-Humanoide
Repositório principal para o projeto do Braço Robótico Humanoide do GER a partir da v2 (2s2026).

Fluxo de uso:

Trabalho principal na branch Develop. Sempre que o estado da develop for considerado uma nova versão estável, será carregado na main.
Para desenvolvimento mais longo de certas features, criar uma branch "feature/[nome]" e passar para a develop quando estiver pronta.
